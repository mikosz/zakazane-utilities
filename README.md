# zakazane-utilities

Set of generic basic utilities for Unreal Engine programming developped in Zakazane - a game studio based in Poland.

Modules:

* [ZakazaneUtilities](./Source/ZakazaneUtilities/README.md) - main module containing general tools
* ZakazaneUtilitiesEditor - editor-specific utilities
* ZakazaneTestUtilities - utilities for implementing automation tests
* ZakazaneValidation - tools for developing asset validators
* ZakazaneUtilitiesTests - contains automation tests for the above modules
